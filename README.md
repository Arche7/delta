# DELTA — учёт расходов и доходов

Telegram-бот, Mini App в стиле «Голограмма» и команда iPhone на двойное касание задней крышки. Все три пишут в одну базу.

- **Бот:** пишете «кофе 350» — расход записан. «+120000 зарплата» — доход. `/rate 100 usd` — курс.
- **Mini App:** карты счетов, график баланса (ведите пальцем), аналитика по дням, курсы и конвертер.
- **Без Telegram:** команда iPhone (`docs/ios-shortcut.md`) и та же страница в Safari на экране «Домой».

## Запуск с нуля — пошагово

Понадобится: аккаунт Telegram, GitHub и Railway. Примерно 20 минут.

### Шаг 1. Создайте бота
1. В Telegram откройте **@BotFather** → `/newbot`.
2. Введите имя (например, `DELTA`) и адрес бота, который заканчивается на `bot` (например, `delta_money_bot`).
3. BotFather пришлёт **токен** вида `123456789:AA…`. Скопируйте его и никому не показывайте.

### Шаг 2. Загрузите код на GitHub
1. На github.com → **New repository** → имя `delta` → **Private** → Create. Ничего не добавляйте (без README).
2. Скопируйте адрес вида `https://github.com/ВАШ_ЛОГИН/delta.git`.
3. Выполните в терминале команды из сообщения Claude (распаковать архив → `git push`).

### Шаг 3. Разверните на Railway
1. railway.com → **New Project** → **Deploy from GitHub repo** → выберите `delta`. Railway найдёт `Dockerfile` и начнёт сборку.
2. Откройте сервис → **Settings** → **Networking** → **Generate Domain**. Скопируйте адрес вида `https://delta-production.up.railway.app`.
3. Подключите постоянный диск: правой кнопкой по сервису (или **+ New**) → **Volume** → путь монтирования **`/data`**. Без диска база будет стираться при каждом обновлении.
4. Вкладка **Variables** → добавьте:
   | Имя | Значение |
   | --- | --- |
   | `BOT_TOKEN` | токен из шага 1 |
   | `PUBLIC_URL` | адрес из п. 2, без «/» в конце |
   | `DB_PATH` | `/data/delta.db` |
5. Railway перезапустит сервис. Откройте `ВАШ_АДРЕС/health` — должно быть `ok`.

При запуске сервер сам подключает бота: webhook, список команд и кнопку **DELTA** в меню чата.

### Шаг 4. Проверьте
1. Боту: `/start` → появится кнопка «Открыть DELTA».
2. Боту: `кофе 350` → ответ «Записано −350 ₽ · Еда».
3. Нажмите кнопку **DELTA** в меню → запись видна, баланс Т-Банка уменьшился.
4. В Mini App: **«Ещё»** → задайте начальные остатки счетов («Изменить») и лимит на месяц.
5. Боту: `/rate 100 usd` — сумма совпадает с экраном «Курсы».

### Шаг 5. Команда iPhone (без Telegram)
Боту `/key` → откройте ссылку из ответа: там пошаговая инструкция с уже подставленными адресом и ключом. Та же инструкция — в `docs/ios-shortcut.md`.

### Шаг 6. Иконка на экране «Домой» (по желанию)
Боту `/web` → откройте ссылку в **Safari** → «Поделиться» → **«На экран Домой»**. DELTA откроется на весь экран без Telegram.

## Команды бота
| Команда | Что делает |
| --- | --- |
| `кофе 350`, `такси 640₽`, `20$ сувенир` | расход; категория угадывается по словам |
| `+120000 зарплата`, `зп 120000` | доход |
| `350 нал` | расход с наличных |
| `/balance` | баланс по счетам и траты за месяц |
| `/rate 100 usd` | пересчёт по курсу |
| `/limit 100000` | лимит трат на месяц |
| `/undo` | удалить последнюю запись |
| `/key`, `/key new` | ключ для команды iPhone, выпустить новый |
| `/web` | одноразовая ссылка входа в Safari |

## Для разработки
См. `ARCHITECTURE.md` → «Local development». Коротко:
```bash
uv run python -m unittest discover -s tests -v       # тесты
uv run python scripts/seed_demo.py data/demo.db       # демо-данные
DB_PATH=data/demo.db RATES_REFRESH=0 uv run uvicorn app.web:app --port 8000
DB_PATH=data/demo.db uv run python scripts/dev_login.py   # ссылка входа для браузера
```
