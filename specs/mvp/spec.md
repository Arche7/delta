# DELTA — первая версия (MVP)

**Статус:** одобрено владельцем 01.10.2026 · **Владелец:** Арсений Чертищев · **Дизайн:** вариант C «Голограмма» (RFC-0001)

## Что получит владелец
Бот в Telegram, Mini App в стиле «Голограмма» и команду iPhone на двойное касание задней крышки. Записать трату можно тремя путями, все данные в одной базе.

## Требования
1. **Бот.** `/start` — приветствие и кнопка «Открыть DELTA». Сообщение вида «кофе 350», «такси 640₽», «20$ сувенир», «+120000 зарплата» сохраняется как запись; бот отвечает «Записано −350 ₽ · Еда» и остатком лимита. Категория угадывается по словам; если не угадана — «Другое». Команды: `/balance`, `/rate 100 usd`, `/key` (личный ключ для команды iPhone), `/limit 110000`, `/undo` (удалить последнюю запись).
2. **Курсы.** Доллар, евро, юань — по ЦБ РФ раз в день; USDT и BTC — CoinGecko раз в час. Каждая запись хранит сумму, валюту, курс на момент записи и сумму в рублях. Старые записи по новому курсу не пересчитываются.
3. **Mini App — 4 экрана как в макете C:**
   - Главная: стопка карт счетов (нажал — следующий счёт), график баланса счёта за 30 дней с «ведением пальцем», категории как «активы» с мини-графиком и % к прошлому месяцу.
   - Аналитика: потрачено и лимит (кольцо), траты по дням столбиками 14Д / 1М / 3М с подсказкой по нажатию и прогнозом, доли категорий, прогноз на конец месяца.
   - Новая запись: окно снизу, своя клавиатура, расход/доход, валюта с пересчётом, категория, счёт, полоска лимита, всплывающее «Записано», лёгкая вибрация Telegram.
   - Курсы: график валюты за 30 дней, список валют с мини-графиками, конвертер в обе стороны.
   - Тёмная и светлая тема — по теме Telegram или iPhone.
4. **Без Telegram.** Та же страница открывается в Safari по ссылке-входу из бота (`/web`) и добавляется на экран «Домой». Команда iPhone отправляет запись на сервер с личным ключом: сумма → тип → категория → уведомление «Записано».
5. **Счета по умолчанию:** Т-Банк (₽), Наличные (₽), Крипто (USDT). Пользователь может переименовать и добавить.
6. **Безопасность:** вход в Mini App — по подписи Telegram; ключ команды iPhone можно сменить командой `/key new`; токены только в переменных окружения Railway.
7. **Анимации** выключаются при «Уменьшении движения»; контраст текста не ниже 4,5:1; кнопки не меньше 44×44.

## Не входит в первую версию
Общий бюджет, подписки и мультиподписка, фото чека, голосовой ввод, выгрузка в Excel.

## Как проверить руками
1. Написать боту «кофе 350» → ответ «Записано −350 ₽ · Еда».
2. Открыть Mini App → запись видна в списке, баланс Т-Банка уменьшился на 350, график обновился.
3. В Mini App добавить «20 $ · Покупки» → в рублях по курсу ЦБ дня.
4. `/rate 100 usd` → сумма в рублях совпадает с экраном «Курсы».
5. `/key` → настроить команду iPhone по инструкции → двойное касание крышки → «Расход» → 500 → «Транспорт» → пришло уведомление, запись видна в Mini App.
6. `/web` → открыть ссылку в Safari → тот же баланс без Telegram.
7. Включить «Уменьшение движения» на iPhone → анимаций нет.
