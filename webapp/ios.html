Команда iPhone «DELTA» — запись трат без Telegram

Команда запускается двойным касанием задней крышки iPhone (или кнопкой «Действие» на iPhone 15 Pro и новее), спрашивает сумму и категорию и отправляет запись на сервер DELTA. В ответ приходит уведомление «Записано −350 ₽ · Еда».

Перед началом возьмите у бота две вещи:

  • адрес сервера — например https://delta-production.up.railway.app;
  • личный ключ — отправьте боту /key. Ключ начинается с dk_. Никому его не показывайте; если он попал не туда, /key new выдаст новый.

Названия действий в «Командах» могут немного отличаться в разных версиях iOS — в скобках указано английское название, по нему тоже ищется.

1. Создайте команду

  1. Откройте приложение «Команды» (Shortcuts) → вкладка «Быстрые команды» → «+» в правом верхнем углу.
  2. Нажмите на название вверху → «Переименовать» → DELTA.

2. Меню из четырёх пунктов

  1. Добавьте действие «Выбрать из меню» (Choose from Menu).
  2. Вопрос: DELTA. Пункты: Расход, Доход, Курс, Баланс (лишние пункты удалите, недостающие добавьте кнопкой «Добавить новый объект»).

3. Пункт «Расход»

Перетаскивайте действия внутрь блока «Расход»:

  1. «Запросить ввод» (Ask for Input): тип — Число, вопрос — Сумма расхода.
  2. «Список» (List): впишите строки Еда, Транспорт, Покупки, Дом, Досуг, Здоровье, Подписки, Другое.
  3. «Выбрать из списка» (Choose from List): список — результат шага 2, вопрос — Категория.
  4. «Получить содержимое URL» (Get Contents of URL):
    • URL: АДРЕС/api/quick (например https://delta-production.up.railway.app/api/quick);
    • нажмите «Показать больше» → Метод: POST;
    • Заголовки → добавить: ключ Authorization, значение Bearer dk_ваш_ключ (слово Bearer, пробел, ключ);
    • Тело запроса: JSON, поля:
    • type — текст exp;
    • amount — переменная «Введённые данные» (Provided Input) из шага 1;
    • category — переменная «Выбранный объект» (Chosen Item) из шага 3.
  5. «Получить значение из словаря» (Get Dictionary Value): ключ text.
  6. «Показать уведомление» (Show Notification): текст — переменная «Значение словаря».

4. Пункт «Доход»

Повторите шаги из пункта 3 внутри блока «Доход» с двумя отличиями:

  • в списке категорий: Зарплата, Фриланс, Подарок, Кешбэк, Другой доход;
  • в теле запроса type — inc.

Подсказка: зажмите действие → «Дублировать», чтобы не собирать заново.

5. Пункт «Курс»

  1. «Запросить ввод»: тип Число, вопрос Сколько?.
  2. «Список»: usd, eur, cny, usdt, btc.
  3. «Выбрать из списка»: вопрос Валюта.
  4. «Получить содержимое URL»: URL АДРЕС/api/quick/rate?amount= + переменная «Введённые данные» + &code= + переменная «Выбранный объект». Метод GET, заголовок Authorization: Bearer dk_ваш_ключ.
  5. «Получить значение из словаря» с ключом text → «Показать уведомление».

6. Пункт «Баланс»

  1. «Получить содержимое URL»: АДРЕС/api/quick/balance, метод GET, тот же заголовок Authorization.
  2. «Получить значение из словаря» text → «Показать результат» (Show Result) — так видно все счета сразу.

7. Повесьте команду на заднюю крышку

Настройки → Универсальный доступ → Касание → Касание задней панели (Back Tap) → Двойное касание → прокрутите вниз до раздела «Быстрые команды» → DELTA.

На iPhone 15 Pro и новее можно ещё: Настройки → Кнопка «Действие» → «Быстрая команда» → DELTA.

8. Проверка

Дважды стукните по крышке → «Расход» → 350 → «Еда». Через пару секунд придёт уведомление «Записано −350 ₽ · Еда», и запись появится в Mini App.

Если что-то не так

Что видноЧто делать
«Нужен вход…»Проверьте заголовок: Authorization, значение Bearer + ключ, без лишних пробелов. Ключ мог смениться после /key new.
«Сумма должна быть числом»В «Запросить ввод» тип должен быть «Число».
Ничего не приходитПроверьте адрес сервера: откройте АДРЕС/health в Safari — должно быть ok.
Категория стала «Другое»Название в списке должно совпадать с категорией в приложении (Еда, Транспорт…).
