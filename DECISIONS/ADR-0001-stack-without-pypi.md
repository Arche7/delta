# ADR-0001 — Стек первой версии без внешних пакетов

**Дата:** 2026-10-02 · **Статус:** принято на время первой версии, владелец может пересмотреть

## Контекст
Владелец выбрал Python с FastAPI и aiogram, хостинг Railway. В рабочей среде, где пишется и проверяется код, каталог пакетов PyPI закрыт (ответ 403), поэтому FastAPI, aiogram, asyncpg и драйверы PostgreSQL нельзя установить и проверить тестами.

## Решение
- Сервер — Starlette (на нём построен FastAPI) и uvicorn: оба доступны и проверены.
- Бот — прямые вызовы Telegram Bot API через webhook, без aiogram.
- База — SQLite из стандартной библиотеки, файл на Volume Railway (`/data/delta.db`).

## Последствия
- Весь код покрыт тестами и проверен в браузере; на Railway ставятся только starlette и uvicorn.
- Без подключённого Volume база стирается при каждом деплое — Volume обязателен.
- Переход на FastAPI/aiogram/PostgreSQL возможен позже: логика вынесена в `app/services.py`, веб-слой и бот тонкие.
